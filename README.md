# マイ情報クリップボード (My Info Clipboard)

非同期のコピペ作業を効率化するための、ブラウザ完結型セキュリティ・情報管理ツールです。

## 👥 誰のためのお手伝い？
- パスワード、住所、電話番号など、普段よく使う個人情報を安全に手元で管理し、1クリックでコピーしたい人。
- 複雑なパスワード管理アプリを使うほどではないが、メモ帳よりは安全に・スマートにコピペしたい個人開発者やフリーランス。

## 🛠 技術スタック
- **Framework:** Next.js (App Router) + React
- **Styling:** Tailwind CSS
- **Storage:** localStorage (外部サーバー送信なし・完全ローカル完結)

## ✨ 主な機能
- **項目ごとのアコーディオン開閉:** 必要な項目だけを開いてスッキリ表示
- **伏字（マスク）機能:** パスワードなどを隠して覗き見を防止
- **簡単コピー & 視覚的フィードバック:** コピーボタンを押すと「完了！」と通知
- **上下ボタンでの並び替え:** 自分の使いやすい順番にカスタマイズ可能
